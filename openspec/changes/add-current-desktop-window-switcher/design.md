# Design

## Context

动机见 proposal.md。现有 GlobalHotKeys 使用 Carbon 注册按下事件；HotKeyText 和 RuleStore 仅接受桌面与管理器动作。WindowCatalog 已提供窗口 ID、Space 成员及隐藏/最小化状态，但完整快照遍历全部桌面并同步读取 AX，不能直接放入键盘回调。概览会把后台窗口重组为独立区域，切换器需要原始归属数据。

SkyLightService.spaces() 仅保留普通 Space，现有 AccessibilityWindowService.focus 使用 activateAllWindows。AppDelegate 的焦点记录依赖 restoreWindowFocus 开关且每桌面只存一个窗口，无法直接用作最近使用列表。现有浮层提供不抢焦点 NSPanel 的基础。

## Goals / Non-Goals

**Goals:** 将候选采集、输入会话、展示及激活验证分开，避免慢速 AX 阻塞输入；保证一轮按键只提交一次，候选始终限定在开始时确定的桌面。

**Non-Goals:** 实时缩略图、窗口移动或关闭、Space 结构管理、原生全屏独立 Space 支持、持久化窗口历史。已有概览和桌面焦点恢复行为保持原有语义。

## Decisions

### 1. 独立的窗口切换会话

新增 WindowSwitcherController 协调输入、候选和面板；可测试的会话状态为 idle → preparing → selecting → committing → idle，任何取消路径均回到 idle。每次会话携带 generation、目标显示器/Space、候选身份和选择 ID，过期异步结果不得打开面板或触发激活。

preparing 期间累计方向步数并记录松键；快速按放后采集完成仍按当次选择提交一次，不闪现滞留面板。窗口身份至少为 PID + windowID + bundleID。候选相对顺序冻结，失效项可标记并跳过，新窗口下次触发再加入。只有收到真实焦点变化后才更新使用顺序。

替代方案：每按 Tab 直接激活会破坏松键确认语义；用完整概览代替会抢焦点且引入搜索、分组等不相关交互。

### 2. Carbon 快捷键配合修饰键监听

复用 Carbon 注册正向和带 Shift 的反向组合，补充仅观察修饰键变化的会话级输入处理，优先使用被动 CGEvent tap；需要的本地事件处理在面板可交互时覆盖取消键。Esc 若需全局拦截，仅在选择会话内启用受限拦截，不能长期吞键或记录文本。所有输入源归一化并去重，释放时结合当前修饰键状态兜底，左右同类修饰键视为一个保持条件。

自定义范围固定为 Tab + 至少一种 Command/Option/Control，可组合，Shift 专用于反向。系统和用户已有绑定一起校验正反向组合。tap 回调只处理状态并派发任务，不查询窗口。处理 tap 被禁用、应用退出、锁屏和睡眠时的解绑与取消；安全输入限制下不承诺拦截成功，失败时不留面板。

替代方案：单用当前按下回调无法识别保持键释放；全程使用主动键盘 tap 会扩大输入影响和权限负担。AltTab 的事件架构仅作参考，不复制其完整框架。

### 3. 目标桌面和候选采集

先通过焦点窗口几何位置/屏幕确定目标显示器，无焦点时使用鼠标屏幕；不能唯一确定则不执行。SkyLightService 增加内部原始当前 Space 查询以识别全屏，不把“普通桌面列表无当前项”错误回退为另一个桌面。

WindowCatalog 增加限定 Space 的采集入口，沿用应用窗口分类与归属查询，包含遮挡、最小化、隐藏和当前窗口，共享窗口去重；不使用 overviewGroups 或 isOnScreen 作为成员条件。系统装饰和自身窗口不列入，AX 不可操作项显示但禁选。普通应用的小窗口不能仅因旧概览的固定尺寸阈值而遗漏；结合 AX 角色判断，避免把菜单、提示气泡混入。

采集在有超时控制的串行工作队列完成，结果回主线程，缓存应用级 AX 查询。复用轻量窗口缓存并在触发时校验当前 Space，按 generation 丢弃过期结果。MRU 通过 AX 焦点通知及应用激活通知维护，有界补查作为兜底，不依赖 restoreWindowFocus 开关；未知窗口按应用名、标题、ID 稳定排序。

### 4. 面板展示

独立非激活 NSPanel 在目标屏幕居中展示列表，包含图标、应用名、标题与状态，支持深浅主题、滚动、高亮和无标题占位。面板不得改变原应用焦点，不使用实时窗口图像。实现前以真实非激活面板验证 Tab/Esc 路由，不能假定面板必然收到本地按键。

### 5. 指定窗口激活

确认时重新核验 PID/窗口 ID/应用身份、真实存在和目标 Space 成员，并确认用户仍处于原目标桌面。先隐藏面板，再按需取消最小化或解除隐藏并请求指定窗口取得焦点；不复用 activateAllWindows 路径，不调用桌面切换或移动接口。必要的定向激活私有桥接放在 Native/SkyLightService，AX 操作仍由 AccessibilityWindowService 承担。

提交后在有限时间内验证前台应用、目标 focusedWindowID、可见状态及原桌面未改变；最多进行有界的同一目标重试，失败提示，不激活替代窗口。不承诺用公共 AX 对所有第三方窗口都成功；先用临时窗口验证同应用跨桌面场景，再决定是否需要私有定向激活桥接。

### 6. 配置与权限

ApplicationSettings 增加可选版本兼容设置：enabled、keyCode（本期仅 Tab）、holdModifiers，默认组合 Option + Tab；旧字段缺失解释为关闭，避免升级后突然占用已有用户的组合。设置使用独立开关和录入控件，HotKeyText/RuleStore 与 GlobalHotKeys 共享保留组合校验，避免文本编辑绕过冲突检测。

注册更新使用准备、校验、持久化和提交过程，部分失败释放新注册并恢复旧注册，磁盘写入失败同样恢复；恢复失败明确显示实际不可用状态。配置仍通过 RuleStore 原子替换保存，备份导入遵循相同校验并保留无关字段。

激活依赖辅助功能，键盘监听按实际 tap 创建与权限检查确认；屏幕录制不足时可尝试从 AX 读标题，否则占位，不因没有缩略图便假定标题权限足够。每个 Bundle ID 独立核验。默认不发送合成键盘事件，不额外要求事件发送权限；若实现采用事件发送则须独立核实。

## Risks / Trade-offs

- [私有 Space/激活接口随系统变化] → 集中桥接、动态能力检查，失败不回退到其他桌面。
- [窗口目录遗漏最小化窗口或小型普通窗口] → 结合 CG、Space 成员和 AX 交叉验证；保留归属不明边界并记录实测限制。
- [快速输入与异步采集发生竞态] → generation、累计方向、释放状态和一次提交控制，并测试乱序事件。
- [第三方应用不接受激活或解除隐藏影响其他窗口] → 同应用跨桌面实测和焦点验证，不宣称所有窗口绝对支持。
- [多屏硬件不可用] → 自动化测试范围解析，实际验收标记未验证，不将模拟结果写为真实多屏通过。

## Migration Plan

先补充配置兼容与状态测试，再完成输入、候选和面板，最后接入激活及设置。旧配置无需重写，用户主动启用。禁用功能即可释放新增快捷键和监听；回滚应用时保留原有配置字段与规则数据。实现阶段运行 ./build.sh，重启本项目应用，验证菜单栏、概览及临时窗口切换，并更新实际能力记录。
