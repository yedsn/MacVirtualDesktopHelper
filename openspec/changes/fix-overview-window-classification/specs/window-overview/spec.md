# Spec Delta

## Purpose

概览以 Option + Tab 的窗口候选规则为准展示各普通桌面，使用相同的窗口采集、标准窗口分类和辅助功能身份检查。被排除的特殊应用窗口集中保留在末尾“其他窗口”，让用户查看并尝试操作，不混入普通候选，也不直接丢弃。

## ADDED Requirements

### Requirement: 概览和窗口切换使用统一候选
概览和 Option + Tab SHALL 共用窗口采集及候选判定，使用相同的小窗口、标准窗口与可读取窗口身份条件。在同一桌面与同一窗口状态下，普通桌面卡片窗口集合 SHALL 等于 Option + Tab 候选集合。排序分别遵循卡片与最近使用顺序。

#### Scenario: 当前桌面列表一致
- **WHEN** 在窗口状态稳定的普通桌面分别打开概览和 Option + Tab
- **THEN** 桌面卡片与切换器包含相同的窗口身份集合，包括符合条件的小窗口、隐藏、最小化及共享窗口

### Requirement: 未激活桌面正常窗口提前展示
概览 SHALL 在普通应用的窗口成员归属明确、且没有非标准窗口证据时，将非当前桌面因 AX 暂不可读的窗口保留所属卡片。用户 SHALL 能从当前桌面直接选中该窗口，系统切换到目标桌面后重新读取并激活指定窗口。此展示不授予批量操作资格。

#### Scenario: 无需先访问其他桌面
- **WHEN** 普通应用窗口在其他已有桌面，CG/Space 可确认窗口存在和归属但 AX 尚未暴露对象
- **THEN** 概览提前显示在所属桌面卡片，用户点选后切换到该桌面、重新读取目标并验证焦点，不放入其他窗口

### Requirement: 特殊窗口集中到末尾
概览 SHALL 将候选检查排除的应用窗口和归属未知的窗口集中显示在最后的“其他窗口”卡片，按窗口身份去重。系统装饰及本应用窗口 SHALL 继续排除。其他窗口卡片 MUST NOT 作为拖放目标。

#### Scenario: 不可切换的后台面板
- **WHEN** 应用窗口记录存在于桌面成员中但不符合 Option + Tab 的标准窗口或辅助功能身份条件
- **THEN** 该记录不在普通桌面卡片和切换列表显示，而在最后的“其他窗口”中显示一次

#### Scenario: 隐藏和最小化候选
- **WHEN** 隐藏或最小化窗口仍符合 Option + Tab 候选条件
- **THEN** 窗口保留在所属桌面并显示对应状态，不单独转移至后台卡片

### Requirement: 操作与状态重验
单窗口操作 SHALL 重验身份、重新读取能力并报告实际结果，不因旧的读取失败永久禁用。其他窗口 MUST NOT 自动进入规则和清理候选。规则应用与清理 SHALL 保留预览、候选移除、确认、执行前重验及结果。

#### Scenario: 特殊窗口恢复操作能力
- **WHEN** 用户对其他窗口尝试操作，目标身份仍匹配且能力已恢复
- **THEN** 允许重试并按实际结果提示，下次采集依据共同规则重新分类

#### Scenario: 特殊窗口清理边界
- **WHEN** 特殊窗口显示在其他窗口卡片
- **THEN** 不因可见而自动进入批量操作，预览后身份、归属、能力或锁定变化的候选被跳过
