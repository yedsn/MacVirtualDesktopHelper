# Design

## Context

用户要求概览以 Option + Tab 列表为准，并将被排除的特殊窗口集中在最后的“其他窗口”。原概览尺寸过滤、后台分组与切换器的标准窗口/AX 身份二次过滤不同，导致窗口集合不一致。

## Goals / Non-Goals

**Goals:** 共享候选判定，保留所有桌面成员关系，集中展示特殊应用窗口，维持操作安全检查。

**Non-Goals:** 不统一最近使用排序与卡片排序，不移动真实窗口，不管理原生 Space 结构，不采集系统装饰窗口。

## Decisions

1. WindowCatalog 对全量及限定桌面快照使用同一小窗口条件，统一标准窗口判定和 AX 身份检查。快照同时携带本次采集的 AX 身份，WindowSwitcherController 直接使用，不再独立查询造成判定分叉。
2. DesktopWindow.isExcludedFromSwitcher 明确区分普通候选和其他窗口；WindowSwitcherSession 也过滤该标记。普通应用在非当前桌面且没有非标准窗口证据时，以 CG/Space 已确认成员补充展示，awaitsDesktopActivation 标记仅影响概览；Option + Tab 仍要求实时 AX 身份。
3. overviewGroups 不再按隐藏或最小化移走窗口。合格窗口留在所属桌面，共享窗口各成员卡片展示；被排除与归属未知项去重放到末尾 otherWindowsSpace。本区域不是 Space，不接受拖放，不成为规则或清理候选。
4. 去除仅针对 accessory 面板的特殊过滤，保留其记录并纳入统一候选判定。单窗口动作继续重验 PID、窗口 ID、应用身份和真实结果。

## Risks / Trade-offs

- [非当前桌面 AX 暂不可读] → 普通应用保留所属桌面，点击后切换再重新读取 AX，验证指定窗口焦点；不授予批量操作资格，也不预先显示无法操作警告。
- [窗口在两个入口采集间变化] → 对稳定临时窗口与当前桌面实际界面比较集合，失效会话仍执行原有重验。
- [采集额外 AX 身份检查增加时间] → 沿用后台队列及会话超时，身份随同一次快照提供，避免控制器重复检查。

## Migration Plan

无持久化迁移。运行测试与构建，重启本应用检查菜单栏、概览、真实 Option + Tab 集合及其他窗口末尾展示。临时窗口结束后清理。多屏和全屏未验证部分独立记录。

## 清理列表同步

清理候选共用 isOverviewDesktopCandidate，计数、预览和锁定规则候选一致。隐藏/最小化与跨桌面预展示项参与预览，其他窗口和保护项排除。cleanupCandidate 分离切换前资格与执行前能力检查：前者允许 awaitsDesktopActivation，后者要求实际可读、标准身份及明确状态。执行始终重新检查成员、身份及保护。

系统可能保留关闭窗口的 CG/Space 记录，WindowCatalog 仅为本应用已确认关闭的窗口保留进程与窗口 ID，刷新时过滤残留；对象重新出现或进程变化则取消过滤，CG 记录消失后移除。同步访问通过锁保护，不记录个人窗口信息到磁盘。

## 规则更新与执行资格分离

桌面规则更新使用 isDesktopRuleUpdateCandidate（普通桌面候选且非共享），无需立即取得 AX 对象，因为更新仅保存已知成员位置。保存前按新采集及原批准变更重验身份、匹配和目标，保持用户字段及歧义排除。应用桌面规则仍保留原有严格执行资格，不因更新预览扩展而扩大自动移动范围。更新锁定规则共用最新普通桌面候选，预览前及保存前排除已保护项。
