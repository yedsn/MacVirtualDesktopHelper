# Design

## Context

动机见 proposal.md。WindowCatalog 已从 SkyLight 获得成员关系，并使用 CoreGraphics 的全窗口列表，但把 containsWindow 返回 false 直接转换为 isAccessibilityUnavailable。Models.belongsToBackgroundSection 将此标记与最小化、应用隐藏合并，overviewGroups 因此会移走归属明确的普通窗口。该布尔值也用于规则候选及清理过滤，不能仅修改分组条件而忽略调用方。

辅助功能读取失败和未找到对象目前都压缩为 nil/false。最小化读取失败还会被默认成 false。已有测试固化了“辅助功能不可用进入后台”的行为，须针对真实用户结果修订。当前桌面切换器使用原始快照与独立激活验证，需要回归其行为。

## Goals / Non-Goals

**Goals:** 桌面归属、可确认的窗口状态、操作能力分别建模；让查询失败保留窗口并提供准确提示，保持批量操作资格不受展示修复影响。

**Non-Goals:** 不通过实际切换全部桌面来枚举窗口，不主动解除用户隐藏或最小化，不修改原生 Space 结构，不新增持久化状态或重写窗口切换器。

## Decisions

### 1. 分组只依赖成员关系与真实后台状态

belongsToBackgroundSection 仅表达已确认最小化或应用隐藏；AX 未读取到的窗口留在已有成员卡片。未知成员继续采用独立归属区域，共享窗口沿用成员列表展示和计数去重。拒绝以 isOnScreen 判断分组：非当前桌面和被遮挡都不代表隐藏。

### 2. 查询结果保留未知语义

在 AccessibilityWindowService 保留读取成功、读取失败及找不到目标的差别，WindowCatalog 按应用在一次采集中复用读取结果并设置有界超时，避免逐窗口重复完整查询。最小化状态使用可表达未知的结果；查询失败不推断 true 或确认为 false，不跨窗口身份复用旧状态。应用隐藏使用 NSRunningApplication 的独立证据。

本次无证据确认最小化且应用未隐藏时，窗口保留桌面并标记“暂时无法操作”；不为此建立跨刷新缓存或长期重试服务。替代方案是保留原有布尔值并只删除一个判断，但它无法说明查询失败，也容易继续把未知当成确定状态。

### 3. 操作能力提示与执行重验独立

普通桌面行增加本地化状态提示，不继续把 AX 缺失描述为“后台窗口”。窗口仍可选择和搜索；用户触发单窗口动作时重新获取目标对象、核验 PID/窗口 ID/应用身份，并沿用焦点等实际结果验证。读取失败提示原因，不将“请求已发出”显示为完成。不因旧能力标记永久禁用重试，也不因失败激活同应用其他窗口。

### 4. 批量资格使用明确判断

检查 belongsToBackgroundSection 的所有调用方，将展示判断与规则更新、清理、规则应用的候选判断分开。保持隐藏、最小化、未知归属及操作能力未知窗口的既有排除边界；批量动作前重验，锁定、预览、移除和结果语义保持完整。不引入通用策略框架，只为实际调用点提供必要的显式资格条件。

### 5. 验证先确认事实再修改说明

实现前用临时 AppKit 窗口比较当前及非当前已有 Space 的 CG 成员、AX 读取与分组，确认 AX 缺失是否解释实际现象；若存在额外成员枚举遗漏，在 WindowCatalog/SkyLightService 既有边界修复，仍不以可见性筛选。只记录临时窗口数据，不提交个人窗口信息。回归包含跨桌面同应用窗口、共享、遮挡、最小化及应用隐藏；权限拒绝和超时可使用可控查询结果验证，实际权限验证不足须明确记录。

## Risks / Trade-offs

- [私有接口或不同应用返回不完整窗口列表] → 使用临时窗口核对成员关系和 CG/AX 证据，不把本次推测写成已复现根因。
- [短暂查询失败使实际最小化窗口暂留原卡片] → 显示未知能力并在下一次采集重验，避免伪造确定状态。
- [共享分类字段调整扩大清理范围] → 审查全部调用方并测试可执行候选；展示位置不授予操作资格。
- [同步 AX 查询拖慢概览] → 每次采集复用应用级结果和有界超时，沿用现有后台刷新及过期结果丢弃。
- [已有在途切换器改动共享采集服务] → 保留其原始成员语义，运行相关回归，不覆盖现有未提交工作。

## Migration Plan

无需迁移用户设置。完成针对性测试后运行 ./Tests/run.sh 和 ./build.sh，重启本项目应用，检查菜单栏及概览，并使用临时窗口完成行为验收与清理。Documentation/Feature-parity.md 记录实际通过项及未验证限制；多屏和全屏不能由单屏普通 Space 结果推定支持。回滚代码即可恢复旧行为，不改变规则或快照数据。
