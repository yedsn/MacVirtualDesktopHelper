构建与稳定签名说明见 [Build-and-signing.md](Build-and-signing.md)。

- Swift/AppKit 负责原生窗口、菜单、表格、卡片、弹窗和键盘交互；SF Symbols、系统字体、语义色与原生材质替换 WinForms 视觉。操作含义、选择规则和确认顺序保持一致。
- Windows 可执行路径/AUMID/窗口类不能直接匹配 Mac 应用。Mac 使用 Bundle ID、应用路径、AX role/subrole 和标题；跨平台导入需预览无法映射项，不能声称自动兼容全部 Windows 规则。
- 优先通过仍存在的 Space 身份定位，必要时明确按保存顺序解析；缺失目标标记不可应用。桌面重排后必须预览解析结果。
- 原生 Space 创建、删除、重命名，以及导入恢复桌面结构按用户前述决定暂不实现。自定义显示名称可在应用内保存，不宣称重命名原生 Space。
- 当前编号直达覆盖单显示器、前 9 个普通桌面且快捷键启用；全屏、多显示器、更多桌面作为兼容性工作单独验证，不能沿用来源原型结论。

## 验收原则

逐项与 Windows 当前交互对照；包含鼠标和键盘，不以按钮存在代替功能完成。窗口操作只测试临时窗口。核心规则匹配、原子持久化、轮转、导入失败回滚使用独立可重复测试；每阶段记录完成、差异、未验证项，不用示例数据代替真实系统操作。
